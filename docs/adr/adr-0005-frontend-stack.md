# ADR-0005: Фронтенд — React + TypeScript + Vite, CSS-токены вместо Tailwind

Дата: 2026-09-14
Статус: Accepted

## Контекст

Промпт допускает «Modern CSS или Tailwind CSS» и требует профессиональный
UI: скруглённые карточки, тонкие тени, статусы (красный/жёлтый/зелёный),
тёмную тему, адаптивность, Lucide-иконки.

## Решение

- Vite + React 18 + TypeScript в строгом режиме (`strict`, `noUnusedLocals`).
  Все относительные импорты — с явными расширениями (совместимо с
  `allowImportingTsExtensions` и консистентно для tooling-проверок).
- Стили — рукописный CSS на дизайн-токенах (`frontend/src/index.css`):
  палитра в CSS-переменных, тема переключается атрибутом
  `data-theme="light|dark"` на `<html>`.
- `lucide-react` — единственная иконочная зависимость.
- Состояние: два контекста (`DataContext` — данные и sync, `SettingsContext`
  — настройки) вместо Redux/Zustand; серверный кэш не нужен, т.к. данные
  небольшие и перезагружаются через `Promise.all` одного «среза».
- Обработка ошибок: классификация на клиенте (`ApiError.status === 0` — сеть),
  скелетоны (`SectionSkeleton`) вместо пустых экранов, EmptyState для всех
  разделов, модалка деталей задания как единая точка «открыть в Classroom».

## Последствия

- Нет генерации утилитарных классов Tailwind — CSS поддерживается вручную, но
  токены дают единый визуальный язык и тривиальную тёмную тему.
- Нулевой FOUC: тема применяется pre-paint скриптом `public/prepaint-init.js`
  (внешний файл, а не inline — CSP §48) до первой отрисовки; режим `system`
  следит за `prefers-color-scheme`. Тем же скриптом ставится `<html lang>`
  (ADR-0034).

## Альтернативы

- Tailwind — отклонён: для одного приложения фиксированного размера ручной CSS
  с токенами компактнее и без конфигурационного оверхеда.
- MUI/AntD — отклонено: «look like Notion/Linear», а не как enterprise-кит.
