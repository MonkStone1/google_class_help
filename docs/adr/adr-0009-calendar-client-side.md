# ADR-0009: Календарные сетки строятся на клиенте

Дата: 2026-09-14
Статус: Accepted

## Контекст

Нужны виды месяц/неделя/день с различимыми по предметам заданиями, без
внешних календарных библиотек (объём данных мал, а зависимости утяжеляют
проект). Бэкенд уже отдаёт задания с `due_at`.

## Решение

- Бэкенд даёт только `GET /api/calendar?from&to` (группировка по дате —
  удобство для отладки/скриптов), но фронтенд строит сетки сам: компонент
  `CalendarPage` группирует кэшированные задания в `Map<день, задания>` и
  рендерит месяц (6×7 от понедельника), неделю (1×7) или день.
- Навигация — курсор-дата в состоянии компонента; «сегодня» подсвечивается,
  дни вне текущего месяца приглушены, до 3 заданий в ячейке + «+N more».
- Цветовые состояния ячейки-чипов: красный (overdue), зелёный (сдано),
  нейтральный (to do); клик по чипу открывает модалку деталей (единая с
  остальными страницами точка просмотра).

## Последствия

- Переключение видов мгновенное — нет запросов к бэкенду при листании.
- Логика дат (`startOfWeek` с понедельника, `dayKey`, `isSameDay`) локализована
  в `frontend/src/dates.ts` и переиспользуется дашбордом и карточками.
- Месячная сетка фиксирована на 6 недель — стабильная высота, вертикальная
  прокрутка внутри ячеек не нужна.

## Альтернативы

- FullCalendar/`react-big-calendar` — отклонено: 40+ КБ и кастомизация ради
  трёх простых видов.
- Полностью серверный календарь (`?view=month`) — отклонено: лишние
  round-trip'ы при листании месяцев.
